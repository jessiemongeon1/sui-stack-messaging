This file covers the TypeScript SDK monorepo (pnpm workspaces + turbo). Root-level guidance in `../AGENTS.md` still applies; this file adds SDK-specific commands, toolchain notes, and invariants.

## Repo layout (this subtree)

```
ts-sdks/
  packages/sui-stack-messaging/    CANONICAL  — published as @mysten/sui-stack-messaging
  pnpm-workspace.yaml              pnpm + minimumReleaseAge floor
  turbo.json                       turbo task graph
  tsconfig.shared.json             shared TS config (NodeNext module resolution)
  prettier.config.js               Prettier (sorted imports via @ianvs plugin)
  .oxlintrc.json                   oxlint rules
  RELEASING.md                     changeset / release workflow
```

Only one package currently lives under `packages/`. The old `build-scripts` package was removed — do not reference it.

## Commands (workspace root)

```bash
pnpm install                       # pnpm >=10.17.0
pnpm build                         # turbo run build
pnpm test                          # turbo run test
pnpm lint                          # oxlint + prettier check
pnpm lint:fix
```

## Commands (inside packages/sui-stack-messaging/)

```bash
pnpm build                         # tsc --noEmit + tsdown (ESM-only output)
pnpm test                          # typecheck + unit
pnpm test:unit                     # vitest run unit
pnpm test:integration              # vitest with localnet config
pnpm test:e2e                      # vitest e2e against testnet (TEST_NETWORK=testnet)
pnpm codegen                       # regenerate Move bindings (sui move summary + sui-ts-codegen)
```

## Toolchain

- pnpm `>=10.17.0` (pinned via `packageManager` in root `package.json`).
- Build: **tsdown** (not esbuild), ESM-only output (`dist/index.mjs` + `dist/index.d.mts`).
- TypeScript module resolution: NodeNext, shared via `tsconfig.shared.json`.
- Lint: **oxlint** (do NOT introduce ESLint — oxlint is the chosen linter here).
- Formatter: Prettier with `@ianvs/prettier-plugin-sort-imports` (don't reorder imports by hand).

## Hard invariants

- **Do not hand-edit `packages/sui-stack-messaging/src/contracts/sui_stack_messaging/`** — every file under that directory is auto-generated by `pnpm codegen` from the Move sources. Hand-edits get silently clobbered the next time codegen runs. (Also enforced as a path-scoped rule under `.claude/rules/`.)
- **Coordinate version bumps via `pnpm changeset`** — never edit `package.json` `version:` fields directly. See `RELEASING.md`.
- **Do not bypass `minimumReleaseAge: 2880`** in `pnpm-workspace.yaml` (2-day floor on new dependency releases; reduces supply-chain attack surface). Mysten packages are excluded by configuration.
- **Do not break the relayer wire protocol.** `RelayerTransport` lives in `packages/sui-stack-messaging/src/relayer/` (not `src/transports/`). Changes here must be coordinated with the Rust relayer and the walrus-discovery-indexer. (Also enforced as a path-scoped rule under `.claude/rules/`.)

## When Move public API changes

Re-run `pnpm codegen` from `packages/sui-stack-messaging/`. Commit the regenerated `src/contracts/sui_stack_messaging/` along with your TS changes. Don't split the regeneration into a separate PR — reviewers need to see both halves together.
